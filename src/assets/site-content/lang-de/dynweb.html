Übersicht

DynWeb – ein minimalistisches System für dynamische Website-Inhalte, mit oder ohne Template. Verfasse deine Inhalte in Word oder LibreOffice und veröffentliche sie als HTML.

Das Repository ist [a href="https://github.com/adrianvla/dynweb"]hier[/a] verfügbar.

[img src="/assets/img/dynweb.webp"][/img]

Nutzung

Richte einen Ordner namens a neben dynweb.js ein und lege deine HTML-Dateien dort ab (zum Beispiel home.html oder hello.html). Erstelle eine HTML-Seite für deine Website und füge ein Element mit der ID content ein (ein dediziertes Tag wird empfohlen). Wenn ein Nutzer auf einen Link klickt oder eine URL wie https://www.example.com/#something besucht, wird das Element mit der ID content mit dem Inhalt von a/something.html gefüllt.

Lizenz: MIT
