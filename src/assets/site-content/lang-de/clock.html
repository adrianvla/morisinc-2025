Work in progress.

Features

Dazu gehören bewegliche Widgets, mehrere Bildschirm-Umgebungen und Animationen.
Ein Kontrollpanel ermöglicht es dir, fast alles zu bearbeiten – inklusive Widget-Positionen und Widget-Code.

Die Zeitdrift auf dem Raspberry Pi Zero wird durch regelmäßige Synchronisation mit einem Online-Zeitserver ausgeglichen.

Widgets

Widgets, die out-of-the-box verfügbar sind:

  • Wochentage (mit Balken, die so aussehen, wenn du auf einen Samstag triffst: ░░ ░░ ░░ ░░ ░░ ▓▓ ░░)
  • Kalender (zeigt das aktuelle Datum mit einem schönen Kalender-Hintergrund an)
  • Digitale Zeit: 3×5-Schrift, HH : MM (: SS, konfigurierbar)
  • Große digitale Zeit: 5×5-Schrift, HH : MM
  • RSS-Feed: Scrollt Nachrichten-Headlines auf dem Display, 8×8-Schrift, unterstützt Lateinisch, Kyrillisch, japanische Kana & Kanji
  • Temperatur: Temperatur°C
  • Wetter: Ein schönes 8×8-Widget mit animierten Icons für jeden Wettertyp, sogar mit einem Partikelsystem für Regen

Bildschirme

Bildschirme sind vergleichbar mit Desktops unter Windows oder macOS. Widgets werden auf Bildschirmen platziert, und basierend auf der Zeit oder Ereignissen (z. B. wenn ein RSS-Update eintrifft) wechseln die Bildschirme mit sanften Animationen.

Kontrollpanel

Mit dem Kontrollpanel kannst du:

  • Das Passwort ändern
  • Anzeigen, was gerade auf dem Display zu sehen ist
  • Die Helligkeit ändern
  • Neu starten
  • Widgets bearbeiten / Neue erstellen, direkt im Browser mit JavaScript (mit Monaco Editor)
  • Bildschirme bearbeiten / Neue erstellen, per Drag-and-drop der Widgets auf einem virtuellen Bildschirm

Nutzung

Besorge dir einen API-Key von weatherapi.com.
Füge ihn in /code/src/widgets/weather/weather.js ein (work in progress; wird ins Kontrollpanel verschoben).

Konfiguriere deine RSS-Feeds in /code/src/widgets/rssFeed/rss.js (work in progress; wird ebenfalls ins Kontrollpanel verschoben).

Erstelle einen systemctl-Service für den Autostart

#!/bin/bash
cd <das Verzeichnis mit dem Inhalt des Code-Ordners>
sudo node src/main.js

und nenne ihn script-startup.service

Und los geht's.

Um das WS281x-Display anzuschließen, verwende GPIO 18 oder ändere den Pin in /code/src/utils/driver.js.
