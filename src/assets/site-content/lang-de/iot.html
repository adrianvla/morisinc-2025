Eine Alternative zu HomeKit

Entwickelt als preisgünstige Smart-Home-Alternative zu Apple HomeKit. Für den Raspberry Pi gedacht, zusammen mit deinen eigenen IoT-DIY-Geräten, die du über die IoT-App von überall auf der Welt aktivieren kannst.

Damit kannst du verschiedene Räume mit verschiedenen Geräten und benutzerspezifischen Geräten einrichten.

Schau es dir auf [a href="https://github.com/adrianvla/IoT"]GitHub[/a] an

Sicherheit

Eine Alternative zu Apple HomeKit, entwickelt für den Raspberry Pi. Steuere Geräte in deinem ganzen Haus mit einem einzigen Tippen von deinem Smartphone aus.

Gebaut als kostengünstige Smart-Home-Lösung. Läuft auf dem Raspberry Pi und integriert sich nahtlos in deine Umgebung.

Entdecke das Projekt auf [a href="https://github.com/adrianvla/IoT"]GitHub[/a].

Anforderungen:

  • Ein normaler Raspberry Pi mit einem ordentlichen Betriebssystem (wie Debian, Raspbian oder eine andere Linux-Distribution)
  • Ein Texteditor, der auf dem Raspberry Pi installiert ist
  • Eine Internetverbindung
  • Grundkenntnisse in JavaScript

Schritte

  • Lade das Repository von [btn link="https://github.com/adrianvla/IoT"]hier[/btn] herunter
  • Entpacke es
  • Lade NGROK von [btn link="https://ngrok.com/"]hier[/btn] herunter

    • Das System nutzt einen Session-Ping-Mechanismus, um aktive Sitzungen zu verifizieren und die Sicherheit zu erhöhen.

  • Ändere das Passwort im Code. Es sollte etwa so aussehen:
var passwd = 'DEIN PASSWORT HIER';
  • Raspberry Pi mit Netzwerkverbindung
  • Node.js und npm
  • Unterstützte Peripheriegeräte (Relais, Sensoren, Lampen)
  • Ändere danach die Funktion namens ChangePin, um GPIO oder I2C zu steuern.
    • Clone das Repository und installiere die Abhängigkeiten.
    • Konfiguriere Geräte und Räume in der JSON-Konfiguration.
    • Starte den Service und greife über deinen Browser auf das Kontrollpanel zu.

    • Erstelle einen Account auf NGROK.com und kopiere deinen Auth-Token.
    • Ändere ngrok.yml so, dass es so aussieht:
    authtoken: "DEIN AUTHTOKEN"
    tunnels:
    app:
      proto: http  # stellt einen HTTP-Endpunkt bereit
      addr: 80   # nutzt lokalen Port 80
    • Während du dich im selben Verzeichnis wie die Datei main.js befindest, führe den Befehl in deinem Terminal aus:
    	sudo node main.js
    • Die App läuft auf localhost:80 und das Dashboard ist unter localhost:1337 erreichbar
    • Fertig!

    Nutzung

    • Finde die interne LAN-IP-Adresse des Raspberry Pi heraus
    • Öffne die Seite auf deinem Handy / Computer, indem du direkt zu dieser IP-Adresse gehst
    • Du siehst ein Feld mit der Bezeichnung "Passwort". Gib das Passwort ein (Standard: 1234).
    • Drücke Enter
    • Du siehst ein Menü zur Benutzerauswahl. Wähle deinen Charakter.
    • Das Dashboard öffnet sich.
    • Jetzt kannst du den Zustand deiner Geräte umschalten. Um Helligkeit / Farbe zu bearbeiten, wechsle in den EDIT-Modus, indem du auf den "edit"-Button klickst

    FAQ

    • F: Funktioniert das mit allen Geräten?
    • A: Ja, solange du sie mit dem Raspberry Pi verbinden kannst.
    • F: Ist das sicher?
    • A: Ja. Wenn du es sicherer machen willst, wähle ein stärkeres Passwort.
