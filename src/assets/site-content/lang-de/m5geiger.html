Ein Geigerzähler auf M5 Stack

Ein smarter Geigerzähler auf Basis des M5Stack, mit einer Strahlungskarte unter Verwendung von OpenStreetMap und Wi-Fi-Logging. Um deinen eigenen zu bauen, lade das Repository [btn link="https://github.com/adrianvla/M5-Stack-Geiger-Counter"]hier[/btn] herunter.

Installation

  • Lade das Repo herunter
  • Ersetze M5.BtnA.isPressed() in Zeile 112 von src/main.cpp, damit es zum Impulssignal deiner Röhre für die Strahlungszählung passt.
if (M5.BtnA.isPressed()) {
    if (flag_tick) {
      signalHandler();

      flag_tick = false;
    }
    } else {
    flag_tick = true;
    }
  • Der 2. Button (Button B) setzt den Zähler zurück
  • Kompiliere das Projekt für M5Stack Core. Ich habe PlatformIO in Visual Studio Code anstelle der Arduino IDE verwendet.
  • Programmiere den M5 Stack mit dem kompilierten Code
  • Schalte den M5Stack ein

Nutzung

  • Schalte den M5Stack ein, indem du den roten Button drückst.
  • Verbinde dein Gerät mit dem M5Stack_setup Wi-Fi-Netzwerk und folge den Anweisungen auf dem M5Stack-Bildschirm.
  • Gehe auf http://192.168.4.1 auf deinem Gerät
  • Fertig!
