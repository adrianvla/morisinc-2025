Обзор

DynWeb — минимальная система для динамического контента сайтов, с шаблоном или без. Пишите контент в Word или LibreOffice и публикуйте как HTML.

Репозиторий доступен [a href="https://github.com/adrianvla/dynweb"]здесь[/a].

[img src="/assets/img/dynweb.webp"][/img]

Как использовать

Создайте папку с именем a рядом с dynweb.js и поместите туда свои HTML-файлы (например, home.html или hello.html). Создайте HTML-страницу для своего сайта и включите элемент с id content (рекомендуется использовать специальный тег). Когда пользователь кликает по ссылке или переходит по URL вроде https://www.example.com/#something, элемент с id content заполнится содержимым файла a/something.html.
