Счётчик Гейгера на M5 Stack

Умный счётчик Гейгера на базе M5Stack с картой радиации на OpenStreetMap и логированием по Wi-Fi. Чтобы собрать свой, скачайте репозиторий [btn link="https://github.com/adrianvla/M5-Stack-Geiger-Counter"]здесь[/btn].

Установка

  • Скачайте репозиторий
  • Замените M5.BtnA.isPressed() на строке 112 файла src/main.cpp на сигнал импульса вашей трубки для подсчёта радиации.
if (M5.BtnA.isPressed()) {
    if (flag_tick) {
      signalHandler();

      flag_tick = false;
    }
    } else {
    flag_tick = true;
    }
  • Вторая кнопка (кнопка B) сбрасывает счётчик
  • Скомпилируйте проект для M5Stack Core. Я использовал PlatformIO в Visual Studio Code вместо Arduino IDE.
  • Запрограммируйте M5 Stack скомпилированным кодом
  • Включите M5Stack

Как пользоваться

  • Включите M5Stack, нажав красную кнопку.
  • Подключите устройство к Wi-Fi сети M5Stack_setup и следуйте инструкциям на экране M5Stack.
  • Перейдите на http://192.168.4.1 на вашем устройстве
  • Готово!
