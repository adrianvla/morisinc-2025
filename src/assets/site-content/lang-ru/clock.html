Возможности

Поддерживаются перемещаемые виджеты, несколько экранов и анимации.
Панель управления позволяет редактировать практически всё: позиции виджетов и их код.

Смещение времени на Raspberry Pi Zero компенсируется периодической синхронизацией с онлайн-сервером точного времени.

Виджеты

Виджеты из коробки:

  • Дни недели (с полосками, которые выглядят так, если сейчас суббота: ░░ ░░ ░░ ░░ ░░ ▓▓ ░░)
  • Календарь (текущая дата на фоне, похожем на календарь)
  • Цифровое время: шрифт 3×5, ЧЧ : ММ (: СС, настраивается)
  • Большое цифровое время: шрифт 5×5, ЧЧ : ММ
  • RSS-лента: прокрутка заголовков новостей на дисплее, шрифт 8×8, поддержка латиницы, кириллицы, японской каны и кандзи
  • Температура: температура°C
  • Погода: красивый виджет 8×8 с анимированными иконками для каждого типа погоды, даже с частицами для дождя

Экраны

Экраны — это аналог рабочих столов в Windows или macOS. Виджеты размещаются на экранах, и в зависимости от времени или событий (например, получения RSS-обновления) экраны переключаются с плавной анимацией.

Панель управления

С панелью управления можно:

  • Сменить пароль
  • Посмотреть, что отображается на дисплее
  • Изменить яркость
  • Перезагрузить
  • Редактировать виджеты / Создавать новые прямо в браузере на JavaScript (через Monaco Editor)
  • Редактировать экраны / Создавать новые перетаскиванием виджетов на виртуальный экран

Как использовать

Получите API-ключ на weatherapi.com.
Вставьте его в /code/src/widgets/weather/weather.js (в процессе разработки; будет перенесено в панель управления).

Настройте RSS-ленты в /code/src/widgets/rssFeed/rss.js (тоже в процессе; тоже будет перенесено в панель управления).

Создайте службу systemctl для автозапуска

#!/bin/bash
cd <директория с содержимым папки code>
sudo node src/main.js

и назовите её script-startup.service

Готово.

Для подключения дисплея WS281x используйте GPIO 18, или поменяйте пин в /code/src/utils/driver.js.
