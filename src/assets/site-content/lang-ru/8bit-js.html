Живое демо [btn link="https://adrianvla.github.io/8BIT-JS-Example/"]здесь[/btn].

Движок использует HTML5 Canvas API и спрайт-листы. Поддерживает бесконечную прокрутку, параллакс-эффекты и системы частиц.

Репозиторий и документация доступны [a href="https://github.com/adrianvla/8BIT-JS"]здесь[/a]. Создавайте ретро или современные игры с удовольствием!

Документация предоставлена в README.md репозитория. Модуль физики всё ещё в разработке. Дизайн напоминает Scratch — используются функции вроде put() и stamp(), — но реализован на JavaScript для производительности и гибкости.
