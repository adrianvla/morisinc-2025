Альтернатива HomeKit

Сделано как более доступная альтернатива Apple HomeKit для умного дома. Для RaspberryPi, чтобы использовать с собственными DIY IoT-устройствами, которыми можно управлять из приложения IoT со смартфона из любой точки мира.

С помощью этого можно настроить разные комнаты с разными устройствами и устройствами для конкретных пользователей.

Смотрите на [a href="https://github.com/adrianvla/IoT"]GitHub[/a]

Безопасность

Альтернатива Apple HomeKit, разработанная для Raspberry Pi. Управляйте устройствами по всему дому со смартфона одним касанием.

Создано как экономичное решение для умного дома. Работает на Raspberry Pi для бесшовной интеграции с вашим окружением.

Изучите проект на [a href="https://github.com/adrianvla/IoT"]GitHub[/a].

Требования:

  • Обычный RaspberryPi с установленной ОС (например, Debian, Raspbian или другой Linux-дистрибутив)
  • Текстовый редактор, установленный на RaspberryPi
  • Подключение к интернету
  • Базовые знания JavaScript

Шаги

  • Скачайте репозиторий [btn link="https://github.com/adrianvla/IoT"]здесь[/btn]
  • Распакуйте
  • Скачайте NGROK [btn link="https://ngrok.com/"]здесь[/btn]

    • Система использует механизм сессионных пингов для проверки активных сессий и повышения безопасности.

  • Поменяйте пароль в коде. Должно выглядеть примерно так:
var passwd = 'ВАШ ПАРОЛЬ ЗДЕСЬ';
  • Raspberry Pi с сетевым подключением
  • Node.js и npm
  • Поддерживаемые периферийные устройства (реле, датчики, свет)
  • После этого измените функцию ChangePin для управления GPIO или I2C.
    • Клонируйте репозиторий и установите зависимости.
    • Настройте устройства и комнаты в JSON-конфигурации.
    • Запустите сервис и откройте панель управления в браузере.

    Как пользоваться

    • Узнайте внутренний LAN IP-адрес RaspberryPi
    • Откройте страницу на телефоне / компьютере, перейдя по этому IP-адресу
    • Вы увидите поле «password». Введите пароль (по умолчанию: 1234).
    • Нажмите Enter
    • Откроется меню выбора пользователя. Выберите персонажа.
    • Откроется панель управления.
    • Теперь можно переключать состояние устройств. Чтобы редактировать яркость / цвет, перейдите в режим EDIT, нажав кнопку «edit»

    FAQ

    • В: Это будет работать со всеми устройствами?
    • О: Да, если вы можете подключить их к raspberry-pi.
    • В: Это безопасно?
    • О: Да. Если хотите повысить безопасность — сделайте пароль посложнее.
