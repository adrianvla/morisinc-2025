概要

Apple Home Kitみたいな感じだけど、無料でRaspberry Pi向け。スマホからワンタップで家のすべてをコントロールできます

HomeKitの代替品

Apple HomeKitより安価なスマートホームの代替品として作りました。RaspberryPi用で、世界中のどこにいてもスマホのIoTアプリから自分のDIY IoTデバイスを操作できます。

これを使えば、部屋ごとに異なるデバイスを設定したり、ユーザー固有のデバイスを設定したりできます。

詳細は [a href="https://github.com/adrianvla/IoT"]GitHub[/a] をチェックしてください

セキュリティ

Apple HomeKitの代替品で、Raspberry Pi向けに設計されています。スマートフォンからワンタップで家じゅうのデバイスをコントロールできます。

コスト効率の良いスマートホームソリューションとして構築。Raspberry Pi上で動作し、既存の環境とシームレスに連携します。

プロジェクトの詳細は [a href="https://github.com/adrianvla/IoT"]GitHub[/a] でご覧ください。

必要なもの

  • OSが正しくインストールされた普通のRaspberryPi（Debian、Raspbian、その他Linuxディストリビューションなど）
  • RaspberryPiにテキストエディタがインストールされていること
  • インターネット接続
  • JavaScriptの基礎知識

手順

  • リポジトリを [btn link="https://github.com/adrianvla/IoT"]こちら[/btn] からダウンロード
  • 解凍する
  • NGROKを [btn link="https://ngrok.com/"]こちら[/btn] からダウンロード

    • このシステムはセッションピングメカニズムを使用して、アクティブなセッションを確認し、セキュリティを強化しています。

  • コード内のパスワードを変更してください。こんな感じになっているはずです:
var passwd = 'YOUR PASSWORD HERE';
  • ネットワーク接続されたRaspberry Pi
  • Node.js と npm
  • 対応周辺機器（リレー、センサー、照明）
  • その後、GPIOまたはI2CをコントロールするためにChangePinという名前の関数を変更してください。
    • リポジトリをクローンして依存関係をインストール。
    • JSON設定でデバイスと部屋を設定。
    • サービスを起動して、ブラウザからコントロールパネルにアクセス。

    authtoken: "YOUR AUTHTOKEN"
    tunnels:
    app:

    	sudo node main.js
    • アプリはlocalhost:80で動作し、ダッシュボードはlocalhost:1337で開く
    • 完了!

    使い方

    • RaspberryPiの内部LAN IPアドレスを確認する
    • スマホやPCからそのIPアドレスに直接アクセスする
    • 「password」というフィールドが表示される。パスワードを入力する（デフォルト:1234）。
    • Enterを押す
    • ユーザー選択メニューが表示される。自分のキャラクターを選ぶ。
    • ダッシュボードが開く。
    • これでデバイスの状態を切り替えられる。明るさや色を編集するには、「edit」ボタンをクリックしてEDITモードに入る

    よくある質問

    • Q: すべてのデバイスで動作しますか?
    • A: はい、Raspberry Piに接続できれば動作します。
    • Q: 安全ですか?
    • A: はい、安全です。より安全にしたい場合は、より強力なパスワードに変更してください。
