M5 Stackで作るガイガーカウンター

M5Stackをベースにしたスマートなガイガーカウンターで、OpenStreetMapを使った放射線マップとWi-Fiロギング機能を搭載しています。自分で作りたい場合は、リポジトリを [btn link="https://github.com/adrianvla/M5-Stack-Geiger-Counter"]こちら[/btn] からダウンロードしてください。

インストール

  • リポジトリをダウンロード
  • src/main.cpp の112行目にある M5.BtnA.isPressed() を、使用しているガイガーチューブのパルス信号に合わせて置き換える
if (M5.BtnA.isPressed()) {
    if (flag_tick) {
      signalHandler();

      flag_tick = false;
    }
    } else {
    flag_tick = true;
    }
  • 2番目のボタン（ボタンB）はカウンターをリセットします
  • M5Stack Core用にプロジェクトをコンパイル。Arduino IDEではなく、Visual Studio CodeのPlatformIOを使用しました。
  • コンパイルしたコードをM5Stackに書き込む
  • M5Stackの電源を入れる

使い方

  • 赤いボタンを押してM5Stackの電源を入れる
  • デバイスを M5Stack_setup Wi-Fiネットワークに接続して、M5Stackの画面に表示される指示に従う
  • デバイスで http://192.168.4.1 にアクセス
  • 完了!
