概要

Raspberry Pi Zeroで動くマトリックス時計で、LaMetric Timeみたいな感じです。
まだ開発中。

ソースコードとビルドファイルは [a href="https://github.com/adrianvla/clock"]こちら[/a] から。

特徴

ウィジェットの移動、複数のスクリーン環境、アニメーションに対応しています。
コントロールパネルから、ウィジェットの位置やコードを含め、ほとんどすべてを編集できます。

Raspberry Pi Zeroの時計のズレは、定期的にオンラインの時刻サーバーと同期することで補正しています。

ウィジェット

標準で用意されているウィジェット:

  • 曜日（土曜日ならこんな感じのバー表示: ░░ ░░ ░░ ░░ ░░ ▓▓ ░░）
  • カレンダー（カレンダー風の背景で今日の日付を表示）
  • デジタル時計: 3x5フォント、HH : MM（: SSは設定可能）
  • ビッグデジタル時計: 5x5フォント、HH : MM
  • RSSフィード: ニュース見出しをディスプレイ上でスクロール表示、8x8フォント、ラテン文字・キリル文字・日本語のカナ＆漢字に対応
  • 気温: temperature°C
  • 天気: 天気タイプごとにアニメーション付きアイコンのかわいい8x8ウィジェット。雨にはパーティクルシステムまで搭載

画面

スクリーンはWindowsやmacOSのデスクトップみたいなものです。ウィジェットはスクリーン上に配置され、時間やイベント（例えばRSSの更新受信）に応じて、スクリーンがスムーズなアニメーションで切り替わります。

コントロールパネル

コントロールパネルでできること:

  • パスワードの変更
  • ディスプレイの表示内容を確認
  • 輝度の調整
  • 再起動
  • ウィジェットの編集 / Monaco Editorを使ってブラウザ上でJavaScriptで新規作成
  • スクリーンの編集 / 仮想スクリーン上でドラッグ＆ドロップして新規作成

使い方

weatherapi.comからAPIキーを取得してください。
/code/src/widgets/weather/weather.js に貼り付けてください（開発中；後にコントロールパネルに移動予定）。

RSSフィードは /code/src/widgets/rssFeed/rss.js で設定してください（開発中；こちらもコントロールパネルに移動予定）。

systemctlサービスを作成して自動起動させます

#!/bin/bash
cd <codeフォルダの中身があるディレクトリ>
sudo node src/main.js

ファイル名は script-startup.service にしてください

これで準備完了です。

WS281xディスプレイを接続するにはGPIO 18を使用するか、/code/src/utils/driver.js でピンを変更してください。
