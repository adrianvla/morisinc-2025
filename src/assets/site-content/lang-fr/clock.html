Fonctionnalités

Les fonctionnalités incluent des widgets déplaçables, plusieurs environnements d'écran et des animations.
Un panneau de contrôle permet d'éditer presque tout, y compris les positions des widgets et le code des widgets.

La dérive de l'horloge sur le Raspberry Pi Zero est atténuée par une synchronisation périodique avec un serveur de temps en ligne.

Widgets

Les widgets fournis par défaut :

  • Jours de la semaine (avec des barres qui ressemblent à ça si on est samedi : ░░ ░░ ░░ ░░ ░░ ▓▓ ░░)
  • Calendrier (indique la date actuelle avec un joli fond de type calendrier)
  • Heure numérique : police 3x5, HH : MM (: SS, configurable)
  • Grande heure numérique : police 5x5, HH : MM
  • Flux RSS : défile les titres d'actualités sur l'affichage, police 8x8, supporte le latin, le cyrillique, le kana et le kanji japonais
  • Température : temperature°C
  • Météo : un joli widget 8x8 avec des icônes animées pour chaque type de temps, avec même un système de particules pour la pluie

Écrans

Les écrans sont analogues aux bureaux sur Windows ou macOS. Les widgets sont placés sur des écrans, et en fonction du temps ou des événements (par exemple, recevoir une mise à jour RSS), les écrans tournent avec des animations fluides.

Panneau de contrôle

Avec le panneau de contrôle, vous pouvez :

  • Changer le mot de passe
  • Voir ce qui est affiché
  • Changer la luminosité
  • Redémarrer
  • Éditer les widgets / En créer de nouveaux en JavaScript directement dans votre navigateur (en utilisant Monaco Editor)
  • Éditer les écrans / En créer de nouveaux en glissant-déposant les widgets sur un écran virtuel

Comment utiliser

Obtenez une clé API de weatherapi.com.
Collez-la dans /code/src/widgets/weather/weather.js (travail en cours ; sera déplacé vers le panneau de contrôle).

Configurez vos flux RSS dans /code/src/widgets/rssFeed/rss.js (travail en cours ; sera aussi déplacé vers le panneau de contrôle).

Créez un service systemctl pour le lancement automatique

#!/bin/bash
cd <the directory containing the contents of the code folder>
sudo node src/main.js

et nommez-le script-startup.service

Et c'est parti.

Pour connecter l'affichage WS281x, utilisez le GPIO 18, ou changez la broche dans /code/src/utils/driver.js.
