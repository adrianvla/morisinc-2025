Un compteur Geiger sur M5 Stack

Un compteur Geiger intelligent construit sur M5Stack, avec une carte de radiation propulsée par OpenStreetMap et un enregistrement Wi‑Fi. Pour construire le vôtre, téléchargez le dépôt [btn link="https://github.com/adrianvla/M5-Stack-Geiger-Counter"]ici[/btn].

Installation

  • Téléchargez le dépôt
  • Remplacez M5.BtnA.isPressed() à la ligne 112 de src/main.cpp pour correspondre au signal d'impulsion de votre tube pour le comptage de la radiation.
if (M5.BtnA.isPressed()) {
    if (flag_tick) {
      signalHandler();

      flag_tick = false;
    }
    } else {
    flag_tick = true;
    }
  • Le 2ème bouton (bouton B) réinitialise le compteur
  • Compilez le projet pour M5Stack Core. J'ai utilisé PlatformIO dans Visual Studio Code au lieu de l'Arduino IDE.
  • Programmez le M5 stack avec le code compilé
  • Allumez le M5Stack

Comment utiliser

  • Allumez le M5Stack en appuyant sur le bouton rouge.
  • Connectez votre appareil au réseau Wi-Fi M5Stack_setup et suivez les instructions sur l'écran du M5Stack.
  • Allez sur http://192.168.4.1 sur votre appareil
  • C'est terminé !
