Vue d'ensemble

DynWeb — un système minimal pour le contenu de sites web dynamiques, avec ou sans template. Rédigez votre contenu dans Word ou LibreOffice et publiez-le en HTML.

Le dépôt est disponible [a href="https://github.com/adrianvla/dynweb"]ici[/a].

[img src="/assets/img/dynweb.webp"][/img]

Comment utiliser

Créez un dossier nommé a à côté de dynweb.js, et placez-y vos fichiers HTML (par exemple, home.html ou hello.html). Créez une page HTML pour votre site web et incluez un élément avec l'id content (une balise dédiée est recommandée). Quand un utilisateur clique sur un lien ou visite une URL comme https://www.example.com/#something, l'élément avec l'id content sera rempli avec le contenu de a/something.html.
