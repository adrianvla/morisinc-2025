Vue d'ensemble

Quick! est une application web qui vous permet de planifier tout, des petites tâches à faire aux énormes projets, à la minute près ou même à la seconde près.

L'application est entièrement open source ; vous pouvez trouver son code source [a href="https://github.com/adrianvla/quick"]ici[/a].

Vous pouvez l'utiliser sur [a href="https://quick.morisinc.net/"]quick.morisinc.net[/a].

Pour le configurer, vous devrez créer une base de données qui peut être utilisée à travers de nombreux services Morisinc comme expliqué [a href="https://decks.morisinc.net/help"]ici[/a].
