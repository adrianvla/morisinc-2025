Vue d'ensemble

Une application de flashcards avec support LaTeX et répétition espacée.

Elle est open source ; le code source est disponible [a href="https://github.com/adrianvla/decks"]ici[/a].

Vous pouvez l'utiliser en ligne sur [btn link="https://decks.morisinc.net/"]decks.morisinc.net[/btn]. Si vous rencontrez des problèmes, veuillez visiter la [a href="https://decks.morisinc.net/help"]page d'aide[/a].

Pour le configurer, vous devrez créer une base de données qui peut être utilisée à travers de nombreux services Morisinc comme expliqué [a href="https://decks.morisinc.net/help"]ici[/a].

Fonctionnalités

  • Support LaTeX
  • Mode flashcard normal (comme Quizlet)
  • Base de données auto-hébergée (requérant à chaque utilisateur de saisir sa propre clé API firebase)
  • Multiplateforme (WebApp en ligne)
  • Import & Export de decks de flashcards
  • Mode sombre & clair

Pourquoi je l'ai créé

J'utilisais auparavant [a href="https://www.studysmarter.de/"]StudySmarter[/a] pour préparer mes examens, mais j'ai rencontré des problèmes d'instabilité en créant des flashcards rapidement.

Deux jours avant mon examen de Calculus I (Partie 1), une partie significative de mes flashcards a disparu à cause de problèmes de plateforme.

En réponse, j'ai construit le premier prototype de cette application en une semaine et je l'ai utilisée pour la Partie 2 de l'examen.

Decks privilégie la stabilité et la création rapide de flashcards pour protéger votre travail.
